# FolioHaven Mobile APK Releases

Official pre-built Android installation packages for FolioHaven Mobile.

- **Release APK**: [`foliohaven-v1.0.0-release.apk`](foliohaven-v1.0.0-release.apk) (~8.36 MB, optimized, minified)
- **Debug APK**: [`foliohaven-v1.0.0-debug.apk`](foliohaven-v1.0.0-debug.apk) (~12.53 MB)

## Features Included in v1.0.0:
- **Formats Supported**: EPUB, MOBI (PalmDOC LZ77), PDF, TXT.
- **Privacy & Security**: 100% Offline, Zero INTERNET permissions.
- **Tablet & Fold Adaptive**: Responsive layout with Two-Column Spread reading, 3-column hero card, and native Navigation Rail on large screens.
- **Reading Controls**: In-book live search, Table of Contents sheet, 4 color palettes, font scaling, line spacing, margins.
- **Text-to-Speech (TTS)**: On-device read aloud with speed, pitch, and language controls.
- **Annotations**: 4-color highlights, notes, and bookmark ribbon.
- **Full Settings Suite**: Persistent reading defaults, TTS defaults, storage usage metrics, cache cleanup, and offline backup/restore via JSON.
